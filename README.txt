MINDMATE AI — STUDENT WELLNESS ASSISTANT
How to run:
1. Extract the project ZIP.
2. Open the MindMateAI_Website folder.
3. Double-click index.html, or open it in a browser.
4. Internet is only needed for the optional Google Fonts import; the app features run locally.

Features:
- Mood check-in with supportive suggestions
- Guided visual breathing exercise with start/stop
- Thought parking lot (page-only; not transmitted)
- Break-a-task-into-a-small-step tool
- Rule-based support chat with predefined responses
- Responsive layout for mobile and desktop
- Support information and safety limitations

Technical honesty:
This is a front-end educational prototype. The chat uses keyword rules and predefined responses; it is not a trained AI model, not connected to a backend, and not a medical diagnostic service. Do not enter sensitive personal details. For formal use, verify local helpline information and consult qualified professionals.
